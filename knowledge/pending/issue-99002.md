# Pending knowledge: issue 99002

Not in the product yet. Becomes current behavior when the issue ships.

- [text-properties] Line height accepts 0.8 to 2.5 in steps of 0.05, with presets "Tight" = 1.0, "Normal" = 1.25 and "Loose" = 1.5; new text keeps its font's own line height until a value is chosen, and after that the last chosen line height is the default for new text. (source: User's answers 1 and 7 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [text-properties] The "Line height" control has preset buttons "Tight", "Normal" and "Loose" (tooltips with the same names, no keyboard shortcuts) and a number field next to them that shows the exact value and accepts a typed value; it is shown when a text, a shape with text or an arrow with a label is selected, or the Text tool is active. (source: Approved answer 4 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [text-properties] A typed line height below 0.8 is set to 0.8, above 2.5 is set to 2.5, and between steps is rounded to the nearest 0.05 (1.23 becomes 1.25, 1.22 becomes 1.20); an empty or non-numeric entry is rejected and the previous value stays. (source: Approved answer 5 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [text-properties] Existing text keeps exactly its current line spacing when line height ships; whenever a text's line height matches no preset, no preset is highlighted and the field shows the exact value. (source: Approved answer 2 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [text-properties] With several texts of different line heights selected, no line height preset is highlighted and the field is empty; clicking a preset or typing a value sets that line height on all of them. (source: Approved answer 6 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [text-properties] Line height can be set on single-line text, where it changes only the text box height; while a text is being edited, the editor shows the same line spacing as the canvas, so lines do not jump when editing starts or ends. (source: Approved answer 9 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [bound-text] Changing line height on text inside a shape keeps it wrapping to the shape width and makes the shape taller, or shrinks it back to its previous height, with its width unchanged; an arrow label stays at the middle of the arrow; a sticky note's auto-fit takes line height into account, so a looser label may be shown smaller, never larger than the picked font size. (source: Approved answer 8 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
- [styles-and-history] Copy styles and paste styles, Ctrl+C then Ctrl+V, Ctrl+D and Alt+drag carry a text's line height, and one line height change is undone with a single undo. (source: Approved answer 10 in the issue 99002 session, 2026-10-11; accepted 2026-10-11 by maxxx)
