# Pending knowledge: issue 11404

Not in the product yet. Becomes current behavior when the issue ships.

- [text-properties] Italic is one property of the whole text element, set by an "Italic" toggle in the properties panel and by Ctrl+I / Cmd+I; there is no separate italic font. (source: PO answer on issue 11404, 2026-10-10; accepted 2026-10-10 by maxxx)
- [text-properties] Fonts without an italic face get a synthetic slant, and italic text must stay readable and unclipped in every script. (source: PO answer on issue 11404, 2026-10-10; accepted 2026-10-10 by maxxx)
- [text-properties] The last chosen italic value becomes the default for new text. (source: PO answer on issue 11404, 2026-10-10; accepted 2026-10-10 by maxxx)
