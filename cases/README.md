# Test cases

The current behavior of Excalidraw, one file per product area. A case describes how the product works today; a change in behavior updates the case that describes it instead of adding a parallel one.

Case format: a `## C-<number> <title>` heading, then Priority and Type, Preconditions, Steps (one action each), Expected result.

These seed cases were written from general knowledge of Excalidraw. UI labels and shortcuts were not checked against the live product; verify them before a real run.
